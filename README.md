# Notch Island · Releases

Versões do **Notch Island**, a ilha dinâmica para o notch do MacBook.

## Instalar

1. Baixe o `NotchIsland-<versão>.dmg` da [última versão](https://github.com/yancaiodesigner/notch-island-releases/releases/latest).
2. Abra o DMG e arraste **Notch Island** para **Aplicativos**.
3. Na primeira vez, clique com o botão direito no app e escolha **Abrir**
   (o app ainda não é notarizado pela Apple).

Depois disso, o app se atualiza sozinho: a ilha mostra quando uma versão nova está sendo instalada.

Requer macOS 14 ou mais recente.
